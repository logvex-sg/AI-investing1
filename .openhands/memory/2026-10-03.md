1. Admin step Continue didn't call createAdmin() (no admin → 401 on generation bootstrap).

3. Generation step bottom Continue silently skipped bootstrap → no generation → /api/system/status + /overview 500.

(and generation status `SETUP_REQUIRED`) when no generation exists; `/api/generations/current` → 404.
Added regression test `test_status_before_bootstrap_is_setup_required`.

Rebuilt sidecar + frontend + shell; verified fresh headless E2E (Xvfb :87) with zero 500s across the
wizard → command center flow (Overview, Network, Portfolio, Strategies). 116 backend tests pass.
